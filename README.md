# nec-upd765a

The NEC uPD765A floppy disk controller.

| Crate | Registry |
|---|---|
| [`emu198x-nec-upd765a`](crates/emu198x-nec-upd765a) | [crates.io](https://crates.io/crates/emu198x-nec-upd765a) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Amstrad CPC 664 and 6128 and the ZX Spectrum +3, through Emu198x's format-amstrad-dsk adapter.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
